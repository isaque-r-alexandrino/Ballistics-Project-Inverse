## Características Principais

**Cálculos Balísticos Reais**
- Trajetória com arrasto usando equações diferenciais
- Densidade do ar calculada a partir de temperatura e pressão
- Correção de vento em ambos os eixos
- Efeito Coriolis opcional
- Bisseção para encontrar o ângulo de elevação com precisão de 0.2 metros

**Interface Profissional**
- Layout limpo e organizado
- Agrupamento lógico dos dados
- Feedback visual dos resultados
- Validação de entrada

**Catálogo de Munições Realista**
- Inclui projéteis reais como M107, M795, M982 Excalibur
- Parâmetros balísticos precisos
- Seleção automática da menor carga capaz de atingir o alvo

**Resultados Detalhados**
- Azimute e elevação em mils
- Tempo de voo
- Velocidade e ângulo de impacto
- Altura máxima da trajetória
- Correções ambientais
